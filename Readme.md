# ZapMeet Backend

ZapMeet is a modern video conferencing and collaboration platform. This is the backend service built with **Node.js**, **TypeScript**, and **Express**.

---

## 🚀 Features

- User authentication with JWT
- Room & meeting management
- WebSocket (real-time) support for chat or signaling
- RESTful APIs with TypeScript support
- MongoDB for database operations
- Environment-based configurations
- Modular code structure

---

## 🛠️ Tech Stack

- **Node.js**
- **Express.js**
- **TypeScript**
- **MongoDB + Mongoose**
- **Socket.IO** (optional)
- **ts-node-dev** for development
